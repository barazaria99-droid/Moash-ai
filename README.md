# מדריך הפעלה — בוט וואטסאפ לקבלת הערכות נזק לרכב

> **למי מיועד המדריך הזה?**
> למי שמנהל מוסך ורוצה להפעיל את הבוט, גם ללא ידע טכני מוקדם.
> כל שלב מוסבר בשפה פשוטה.

---

## מה הבוט הזה עושה?

כאשר לקוח שולח הודעה לוואטסאפ העסקי שלכם, הבוט:

1. **מברך את הלקוח** בעברית ומסביר שהוא יעזור לו לקבל הערכה ראשונית
2. **שואל שאלות** אחת-אחת: שם, טלפון, דגם הרכב, שנת ייצור, תיאור הנזק, מעורבות ביטוח
3. **מבקש 4–6 תמונות** של הרכב מזוויות שונות
4. **שולח את התמונות לבינה מלאכותית** שמנתחת את הנזק
5. **שולח ללקוח הערכה ראשונית** כולל: סיכום הנזק, חלקי הרכב שנפגעו, רמת חומרה, טווח עלות בשקלים, והבהרה שזו הערכה ראשונית בלבד
6. **שומר הכל** בממשק ניהול שרק אתם רואים

## מה צריך לפני שמתחילים?

תצטרכו לפתוח **4 חשבונות חינמיים** (ואחד בתשלום). הנה הסבר על כל אחד:

### 1. Twilio — חשבון לשליחת/קבלת הודעות וואטסאפ

Twilio הוא שירות שמחבר את הבוט לוואטסאפ.

- פתחו חשבון חינמי בכתובת: https://www.twilio.com/try-twilio
- לאחר הרשמה, לכו ל-**Console → Account Info**
- שמרו לצד:
  - **Account SID** (נראה כך: `ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)
  - **Auth Token** (לחצו על העין להצגה)
- לכו ל-**Messaging → Senders → WhatsApp Sandbox**
- שם תמצאו מספר טלפון לבדיקות (**+1 415 523 8886**)

> ⚠️ **חשוב**: לצורך שימוש עם מספר הוואטסאפ העסקי שלכם (ולא מספר sandbox לבדיקות), תצטרכו לפתוח בקשה ל-WhatsApp Business API דרך Twilio — זה תהליך של מספר ימים. לבדיקות ראשוניות, ה-sandbox מספיק.

---

### 2. OpenAI — חשבון לבינה המלאכותית שמנתחת את התמונות

- פתחו חשבון בכתובת: https://platform.openai.com/signup
- לכו ל-**API Keys** ולחצו על **Create new secret key**
- שמרו את המפתח (נראה כך: `sk-proj-...`) — **הוא יוצג רק פעם אחת**
- לכו ל-**Billing** והוסיפו אמצעי תשלום (החיוב לפי שימוש, ניתוח תמונה עולה כמה סנטים)

---

### 3. Python — שפת התכנות שבה הבוט כתוב

Python היא תוכנה שצריך להתקין על המחשב.

- הורידו מהכתובת: https://www.python.org/downloads/
- התקינו כרגיל (לחצו "Next" בכל שלב)
- בסיום, פתחו **Terminal** (מק) או **Command Prompt** (ווינדוז) והקלידו:
  ```
  python3 --version
  ```
  אם מופיעה גרסה (לדוגמה `Python 3.12.0`) — הכל טוב.

### 4. ngrok — כלי שחושף את הבוט לאינטרנט

ngrok מאפשר ל-Twilio "להגיע" לבוט שרץ על המחשב שלכם.

- הורידו והתקינו מהכתובת: https://ngrok.com/download
- פתחו חשבון חינמי (נדרש לאימות)

## הוראות הפעלה שלב-אחר-שלב

### שלב 1 — הורידו את קבצי הבוט למחשב

אם קיבלתם תיקייה עם הקבצים, פשוט העבירו אותה לשולחן העבודה.

אם קיבלתם קישור לGitHub:
```
git clone <הקישור> Mosah
```

---

### שלב 2 — צרו את קובץ ההגדרות

בתוך תיקיית הפרויקט, צרו קובץ בשם `.env` (שימו לב: נקודה בהתחלה).

הדרך הקלה ביותר: **העתיקו את הקובץ `.env.example` ושנו את שמו ל-`.env`**.

פתחו את הקובץ `.env` בעורך טקסט (Notepad, TextEdit) ומלאו את הפרטים:

```
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx     ← העתיקו מ-Twilio Console
TWILIO_AUTH_TOKEN=your_auth_token_here                   ← העתיקו מ-Twilio Console
TWILIO_WHATSAPP_NUMBER=whatsapp:+14155238886              ← זה המספר של ה-Sandbox

OPENAI_API_KEY=sk-proj-...                               ← העתיקו מ-OpenAI

SHOP_NAME=מוסך ישראל                                    ← שם המוסך שלכם (יופיע ללקוחות)

ADMIN_USERNAME=admin                                     ← שם משתמש לממשק הניהול
ADMIN_PASSWORD=הסיסמה_שלכם                              ← בחרו סיסמה חזקה
```

שמרו את הקובץ.

---

### שלב 3 — התקינו את הספריות הנדרשות

פתחו **Terminal** (מק) או **Command Prompt** (ווינדוז), נווטו לתיקיית הפרויקט:

```bash
cd Desktop/Mosah
```

הריצו את הפקודות הבאות אחת-אחת:

```bash
python3 -m venv venv
```
(יוצר סביבה וירטואלית — תיקייה בשם `venv` תיווצר)

```bash
source venv/bin/activate
```
(במק. בווינדוז: `venv\Scripts\activate`)

לאחר הפקודה הזו אתם תראו `(venv)` בתחילת השורה — זה תקין.

```bash
pip install -r requirements.txt
```
(מתקין את כל הספריות הנדרשות — יכול לקחת דקה)

### שלב 4 — הפעילו את הבוט

```bash
uvicorn app.main:app --reload --port 8000
```

אם הכל עובד, תראו משהו כזה:
```
INFO | startup | shop=מוסך ישראל db=sqlite:///./mosah.db
INFO | Uvicorn running on http://127.0.0.1:8000
```

**השאירו את החלון הזה פתוח** — זה הבוט שרץ.

---

### שלב 5 — חשפו את הבוט לאינטרנט עם ngrok

פתחו **חלון Terminal חדש** (בלי לסגור את הקודם) והריצו:

```bash
ngrok http 8000
```

תראו שורה כזו:
```
Forwarding  https://abcd-1234.ngrok-free.app → http://localhost:8000
```

העתיקו את הכתובת שמתחילה ב-`https://` (למשל `https://abcd-1234.ngrok-free.app`).

> ⚠️ **כל פעם שאתם מפסיקים ומפעילים מחדש את ngrok, הכתובת משתנה**. תצטרכו לעדכן ב-Twilio (ראו שלב הבא).

---

### שלב 6 — עדכנו את Twilio עם הכתובת של הבוט

1. לכו ל-**Twilio Console → Messaging → Senders → WhatsApp Sandbox**
2. בשדה **"When a message comes in"** הדביקו:
   ```
   https://abcd-1234.ngrok-free.app/webhook/whatsapp
   ```
   (החליפו את הכתובת בכתובת שקיבלתם מ-ngrok)
3. ודאו שהשיטה היא **HTTP POST**
4. לחצו **Save**

## ממשק הניהול — לוח הבקרה שלכם

לאחר שהבוט עובד, תוכלו לראות את כל הפניות בכתובת:

```
http://localhost:8000/admin/
```

שם תכניסו את שם המשתמש והסיסמה שהגדרתם בקובץ `.env`.

### מה תראו שם?

**כרטיסי סטטיסטיקה** בראש הדף:
| כרטיס | משמעות |
|---|---|
| סה"כ פניות | כל הלקוחות שפנו |
| חדשות | לקוח התחיל אבל לא סיים |
| ממתינות לתמונות | שאלות הושלמו, מחכים לתמונות |
| מוכנות להערכה | תמונות התקבלו, ממתין לניתוח |
| הוערכו | הבינה המלאכותית שלחה הערכה ללקוח |
| דורשות בדיקה | משהו לא עבד, צריך לטפל ידנית |
| תואמו | תיאמתם פגישה עם הלקוח |

**טבלת פניות** עם כל הפרטים — לחצו על "פרטים ←" לראות פניה מלאה.

**בדף הפניה המלאה** תוכלו:
- לראות את כל פרטי הלקוח, הרכב והנזק
- לראות את ניתוח הבינה המלאכותית עם הערכת מחיר
- לראות את תמונות הרכב
- לשנות את הסטטוס (לדוגמה: לסמן "תואם" אחרי שדיברתם עם הלקוח)
- לכתוב הערות פנימיות (לא נשלחות ללקוח)

## טיפים לשימוש יומיומי

**בכל בוקר**, פתחו את ממשק הניהול וסנו לפי "הוערכו" — אלו הלקוחות החדשים שקיבלו הערכה ומחכים לשיחה.

**כשאתם מתקשרים לקוח**, עדכנו את הסטטוס ל"תואם" ורשמו הערה פנימית ("נקבעה פגישה לג׳, 14:00").

**אם הלקוח לא ענה על כל השאלות**, הוא יופיע בסטטוס "חדש" או "ממתין לתמונות" — תוכלו לפנות אליו ישירות.

**לקוח שרוצה להתחיל מחדש** — שיכתוב "התחל מחדש" בוואטסאפ.

## שאלות נפוצות

**ש: הבוט לא עונה ללקוחות — מה קורה?**
ת: בדקו שהחלון עם `uvicorn` פתוח ופועל. בדקו שה-ngrok פועל. בדקו שהכתובת ב-Twilio מעודכנת.

**ש: הלקוח שלח תמונות אבל הן לא מופיעות בממשק.**
ת: ייתכן שבעיית הורדה. בדף הפניה מופיעים גם קישורי המקור מ-Twilio שניתן לפתוח ידנית.

**ש: הניתוח חזר עם "דורש בדיקה אנושית".**
ת: הבינה המלאכותית לא הייתה בטוחה מספיק — ייתכן שהתמונות לא היו ברורות. צרו קשר עם הלקוח ובקשו תמונות טובות יותר, או קבעו ביקור לבדיקה פיזית.

**ש: רוצה לשנות את שם המוסך שמופיע ללקוחות.**
ת: פתחו את קובץ `.env` ושנו את `SHOP_NAME=`.

**ש: איך מוסיפים עובד נוסף שיכול לראות את הממשק?**
ת: כרגע יש רק משתמש מנהל אחד. ניתן לשתף את שם המשתמש והסיסמה עם הצוות.

## מידע טכני (למפתחים)

```
app/
├── main.py              — FastAPI factory, mounts, lifespan
├── config.py            — Pydantic settings from .env
├── database.py          — SQLAlchemy engine + session dependency
├── logger.py            — Structured logging setup
├── models/models.py     — Conversation + Message ORM models; LeadStatus + ConversationState enums
├── services/
│   ├── conversation.py  — 10-state machine, photo accumulation, validation, background analysis
│   ├── openai_service.py — OpenAI Responses API (gpt-4o vision), Hebrew formatter
│   └── twilio_service.py — TwiML builder, media download, proactive send
└── routers/
    ├── webhook.py       — POST /webhook/whatsapp with full error isolation
    └── admin.py         — HTTP Basic Auth dashboard with Hebrew labels

LeadStatus auto-transitions (bot-driven):
  new → awaiting_photos → ready_for_estimate → estimated
                                              → needs_human_review (low confidence / error)

Manual transition (admin):
  any → booked

Production checklist:
  □ docs_url=None in main.py
  □ Strong ADMIN_PASSWORD
  □ PostgreSQL instead of SQLite
  □ Object storage (S3) for uploads
  □ HTTPS + domain
  □ Twilio webhook signature validation
```
